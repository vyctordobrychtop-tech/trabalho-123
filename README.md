# Jogo dos Ingressos

Programa em Python que pratica variaveis, operadores matematicos, condicionais,
funcoes e estruturas de repeticao.

Antes de iniciar a partida, o programa verifica se:

- o total de alunos, monitores e convidados cabe nos 100 ingressos;
- a quantidade de convidados nao ultrapassa 20 pessoas.

Quando o evento e aprovado, o jogador se movimenta pelo mapa usando `w`, `a`,
`s` e `d`. Cada ingresso encontrado vale 10 pontos.

## Como executar

```bash
python3 jogo.py
```
